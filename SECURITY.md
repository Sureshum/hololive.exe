# Security Policy

## Reporting a vulnerability

This is a harmless educational prank script with no server, no auth, and no
external dependencies. It should have no security surface.

If you still find something wrong, report it through the repository's
**Security tab > Report a vulnerability** (private), instead of opening a
public issue or emailing anyone.

## Things already handled

- No tokens, passwords, API keys or personal data are stored in this repo.
- Commits use a GitHub noreply address; keep it that way.
- Secret scanning and push protection are enabled on the repository.
- GIFs are downloaded from Tenor only, never executed as code.
